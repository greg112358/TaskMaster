This is a desktop app that allows a family to coordinate chores / calendars

## general guidelines
there should be hints at what voice cmds are in the touchscreen interface
there should be a way to do stuff with both the touchsceen and voice cmds
if a voice cmd is not understood, say "i missed that"
ui should be easy to see at a glance from about 10 feet away. make big
## Grocery View
Shows 3 list simultaneously with different color text
red list which is meat and dairy
green list which is produce
black list which is everything else
voice cmds "add milk to groceries"->adds milk to red list
"clear groceries" erases all items on all lists
Should be able to navigate to grovery view with "show groceries" or touchscreen navigation
## calendar view (default)
Should be ability to add people (fairly uncommon task)
Should be able to navigate to grovery view with "show calendar" or touchscreen navigation
Should be able to add chores via voice interface:
"Add task for Greg ("for _" is optional) clean cat tree every 2 weeks" if name is unrecognized, don't assign task.
Should be a month/week view, should be toggleable
"Add event Cat's Birthday every year"
events/tasks should be able to be reoccuring (every day, every saturday, once a month, once every x days,weeks,months), annually)
## chore list
list of currently scheduled chores (chore description, date it's scheduled, date it was last done, person it's assigned to)
